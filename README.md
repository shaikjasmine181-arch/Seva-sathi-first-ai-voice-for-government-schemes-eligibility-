# Seva Saathi – AI Voice for Government Scheme Discovery and Eligibility

## 🚀 Project Overview
Seva Saathi is an AI-powered voice assistant designed to help citizens discover government schemes and understand their eligibility. It provides a simple and accessible way to explore government welfare schemes using voice-based interaction.

The system aims to make government scheme information easier to understand, especially for rural citizens and people with limited digital literacy.

## 🎯 Problem Statement
Many citizens are unaware of government welfare schemes or face difficulties understanding eligibility criteria, application procedures, and required documents. Language barriers and complicated websites make accessing government benefits challenging.

## 💡 Proposed Solution
Seva Saathi provides a voice-based AI solution that helps users:
- Discover government schemes.
- Understand eligibility criteria.
- Get information about required documents.
- Learn how to apply for schemes.
- Interact using simple voice commands.
- Access information in regional languages.

## ⚙️ Working Process
1. User opens the Seva Saathi application.
2. User asks a question through voice or text.
3. The system converts voice input into text.
4. AI processes the user's query.
5. The system identifies relevant government schemes.
6. Eligibility criteria and scheme details are displayed.
7. The system provides responses through text and voice.
